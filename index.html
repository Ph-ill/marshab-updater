3MicroPython runtime

Loading runtime list.

  1. Download the .uf2 for your board below and check its sha256.
  2. Press Restart in BOOTSEL, or hold BOOTSEL while plugging the board in.
  3. Drag the .uf2 onto the RPI-RP2 drive. The board restarts on its own.
  4. Connect again and install the ship software (section 2).

Runtime images come straight from micropython.org. Hover a checksum for the command that verifies it.

    7Recovery

    • Ship will not connect: unplug it, hold BOOTSEL, plug it in, then load the runtime (section 3) and install again.
